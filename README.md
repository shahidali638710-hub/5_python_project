# 5_python_project
# 🐍 Python Beginner Projects

This repository contains a collection of beginner-friendly Python projects created to practice programming fundamentals, logic building, conditional statements, loops, functions, user input, and basic problem-solving.

## 📂 Projects Included

### 1. 🎮 Choose Your Own Adventure

**File:** `choose_your_own_adventure.py`

A text-based adventure game where the player makes different choices and gets different outcomes based on their decisions.

**Concepts Practiced:**

* User input
* `if`, `elif`, `else`
* Nested conditions
* String methods
* Decision making

---

### 2. 🔢 Number Guesser

**File:** `number_guesser.py`

A number guessing game where the user tries to guess a hidden number.

**Concepts Practiced:**

* User input
* Variables
* Conditional statements
* Loops
* Random numbers
* Comparison operators

---

### 3. 🔐 Password Manager

**File:** `password_manager.py`

A simple password manager project for practicing basic data handling and user interaction in Python.

**Concepts Practiced:**

* User input
* Variables
* Strings
* Data storage
* Functions
* Basic program logic

---

### 4. 🧠 Quiz Game

**File:** `quiz_game.py`

A simple quiz game that asks questions, checks the user's answers, and provides a result based on the responses.

**Concepts Practiced:**

* User input
* Conditional statements
* Variables
* Lists/dictionaries
* Score calculation
* Basic logic

---

### 5. ✊ Rock Paper Scissors

**File:** `rock_paper_scissors.py`

A classic Rock Paper Scissors game where the user plays against the computer.

**Concepts Practiced:**

* User input
* Conditional statements
* Loops
* Random selection
* Comparison logic
* Game logic

---

## 🛠️ Technologies Used

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open any `.py` file.
5. Run the program using:

```bash
python filename.py
```

For example:

```bash
python rock_paper_scissors.py
```
